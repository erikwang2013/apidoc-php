Go 使用指南

接口文档以类型化结构体随路由注册，内嵌 Web UI 提供浏览与在线调试；兼容 net/http、Gin、Echo、Chi、Fiber、beego、Kratos、go-zero。

  • 安装、Config 与 Router
  • Route / Doc / Param / Response
  • 8 个框架适配器

Rustv2.0.0

Rust 使用指南

用过程宏在 handler 上声明文档，编译期静态注册，运行期零成本聚合；兼容 axum 与 actix-web，内置鉴权、Mock、导出、分享与代码生成。

  • 依赖、宏与编译期规则
  • axum / actix-web 接入
  • 鉴权、Mock、多应用版本
  • 导出、代码生成、场景与排错

UIVue 3.5

apidoc-ui 使用指南

Vue 3 + TypeScript 的文档加载与展示页面，支持应用/版本、在线调试、接口分享、Swagger 导出、缓存管理与多语言。构建产物为纯静态文件。

  • 构建与部署
  • config.js 运行时配置
  • 多 Host / appKey / 鉴权
  • 调试事件、Mock 扩展与排错
