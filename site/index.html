一个项目家族，一套文档体验。

Apidoc 把接口文档从手写 Markdown 变成代码旁的声明。PHP 版使用 PHP 8 attributes，Go 版使用类型化结构体，Rust 版使用过程宏；三者共享同一套文档模型、在线调试与静态前端。PHP 版还可调试 MQTT、gRPC、TCP 等任意协议，并解析 OpenAPI、protobuf、WSDL 等定义文件。

PHP 版源自 HGthecode/apidoc-php（hg/apidoc）；Go、Rust 与 apidoc-ui 由 erikwang2013 维护。每种语言保留自己的安装与接入方式，文档体验保持一致。

从声明到交付，三种语言走同一条文档流水线。

PHP >= 8.0Go >= 1.24Rust >= 1.82MIT

同一个接口，三种写法。

不需要迁移技术栈。用你现有的语言声明路由与文档，Apidoc 负责生成、调试与交付。

PHP阅读使用指南
User.php
use erikwang2013\apidoc\annotation as Apidoc;

#[Apidoc\Title("Get user")]
#[Apidoc\Method("GET")]
#[Apidoc\Url("/users/{id}")]
#[Apidoc\RouteParam(
    name: "id", type: "int"
)]
#[Apidoc\Returned(
    name: "name", type: "string"
)]
public function show(int $id) { }
Go阅读使用指南
main.go
s.Register(apidoc.Route{
    Method: "GET",
    URL:    "/users/:id",
    Handler: getUser,
    Doc: apidoc.Doc{
        Title: "Get user",
        Params: []apidoc.Param{
            {Name: "id", In: "path",
             Type: "int", Required: true},
        },
        Responses: []apidoc.Response{
            {Name: "name", Type: "string"},
        },
    },
})
Rust阅读使用指南
user.rs
#[apidoc::title("Get user")]
#[apidoc::method("GET")]
#[apidoc::url("/users/{id}")]
#[apidoc::route_param(
    name = "id", ty = "int", required
)]
#[apidoc::returned(
    name = "name", ty = "string"
)]
async fn get_user() {}

同一套文档体验，各自原生。

从在线调试到鉴权、导出与共享 UI，核心工作流一致；具体能力以各语言指南为准。

任意协议调试

HTTP/WebSocket/SSE 由浏览器直连；MQTT、STOMP、gRPC、TCP/UDP 等经服务端中继。目标只来自注解，中继默认关闭。

字段级 Mock 示例。PHP 支持规则表达式，Go 按类型生成，Rust 提供 15 条 fake 规则。

多应用 / 多版本

一套文档管理多个应用与版本，按应用树切换；接口归属与访问密码可以独立配置。

api v1admin v2open v3

鉴权与缓存

全局密码与应用独立密码；文档缓存、ETag/304 与常量时间比较，读接口本机处理 P95 < 10ms。
