# Apidoc 使用说明

## 一、介绍

Apidoc 是基于 **PHP 8 attributes 注解体系**生成 API 文档的 composer 扩展包（包名 `erik/apidoc`，命名空间 `erikwang2013\apidoc`），同时提供在线调试、Mock、Json/TypeScript 代码生成、接口生成器、代码生成器、数据表字段引用等能力。

- 本项目是 [HGthecode/apidoc-php](https://github.com/HGthecode/apidoc-php) 的 fork，由 erik 维护。
- **仅支持 PHP >= 8.0**，注解一律使用 PHP 8 原生 attributes 书写（`#[注解名(...)]`），不支持旧版 `@注解` 原始注解写法（doctrine 注解依赖已移除）。

## 二、安装

```bash
composer require erik/apidoc
```

- 要求 PHP >= 8.0（attributes 语法依赖）
- 包名 `erik/apidoc`；若 Packagist 尚未发布，可在 `composer.json` 的 `repositories` 中配置指向本仓库安装
- 安装完成后无需额外配置即可编写注解，文档默认挂在 `/apidoc` 路由下（可通过配置键 `route_prefix` 修改）

## 三、框架接入

### Laravel（>= 8.x）

composer 的 `extra.laravel.providers` 已配置 `erikwang2013\apidoc\providers\LaravelService`，安装后自动注册，无需手动添加 Provider。

发布配置文件（生成 `config/apidoc.php`）：

```bash
php artisan vendor:publish --provider="erikwang2013\apidoc\providers\LaravelService"
```

编辑 `config/apidoc.php` 按需修改配置，访问 `http://你的域名/apidoc` 打开文档。

### ThinkPHP 5 / ThinkPHP 6

composer 的 `extra.think.services` 已配置 `erikwang2013\apidoc\providers\ThinkPHPService`（TP5 使用 `ThinkPHP5Service`），安装后自动注册。`extra.think.config` 会将 `src/config.php` 合并到应用配置，配置键为 `apidoc`：

```php
// config/apidoc.php
return [
    'apps' => [
        [
            'title' => 'Api接口',
            'path'  => 'app\controller',
            'key'   => 'api',
        ],
    ],
    // ...其余配置项同默认配置
];
```

访问 `http://你的域名/apidoc` 查看文档。

### Hyperf（>= 2.x）

composer 的 `extra.hyperf.config` 已指向 `erikwang2013\apidoc\ConfigProvider`，自动注册。将 `src/config.php` 复制到 `config/autoload/apidoc.php` 后修改即可：

```php
// config/autoload/apidoc.php
return [
    'title' => 'Apidoc',
    'apps'  => [
        [
            'title' => 'Api接口',
            'path'  => 'app\Controller',
            'key'   => 'api',
        ],
    ],
];
```

### Webman（>= 1.x）

Webman 的插件机制会自动加载 `config/plugin/erik/apidoc/config.php`。将包内 `config.php` 复制到该位置并按需修改，重启 Webman 后访问 `/apidoc` 即可。

### Yii 2

Yii 2 采用手动注册方式，在应用入口（`web/index.php`）加载框架后调用 `\erikwang2013\apidoc\providers\Yii2Service::register()`：

```php
// web/index.php
require __DIR__ . '/../vendor/autoload.php';

defined('YII_DEBUG') or define('YII_DEBUG', true);
defined('YII_ENV') or define('YII_ENV', 'dev');

require __DIR__ . '/../vendor/yiisoft/yii2/Yii.php';

$config = require __DIR__ . '/../config/web.php';
$app = new yii\web\Application($config);

// 注册 Apidoc 服务（需在 $app->run() 之前、应用创建之后，urlManager 需开启 enablePrettyUrl）
\erikwang2013\apidoc\providers\Yii2Service::register();

$app->run();
```

配置通过 Yii 2 配置文件的 `params['apidoc']` 提供：

```php
// config/web.php
return [
    'components' => [
        'urlManager' => [
            'enablePrettyUrl' => true,
            // ...
        ],
    ],
    'params' => [
        'apidoc' => [
            'title' => 'Api接口',
            'apps'  => [
                [
                    'title' => '接口文档',
                    'path'  => '@app/controllers',
                    'key'   => 'api',
                ],
            ],
        ],
    ],
];
```

注意：Yii2 的 `urlManager` 必须开启 `enablePrettyUrl`，否则 Apidoc 路由无法生效。

### Yii 3

Yii 3 同样为手动调用 `\erikwang2013\apidoc\providers\Yii3Service::register()`，需要传入 PSR-11 容器（可选第二个参数直接传配置数组）：

```php
// public/index.php
$container = require __DIR__ . '/../config/container.php';

\erikwang2013\apidoc\providers\Yii3Service::register($container);
// 或直接传配置：\erikwang2013\apidoc\providers\Yii3Service::register($container, $config);
```

配置同样通过 `params['apidoc']` 提供（结构同 Yii 2 示例）。

## 四、配置参数

以下为 `src/config.php` 中可配置的全部参数。完整配置代码见本文件末尾【附录：完整配置代码】，各键说明如下。

### title / desc

- `title`：（选配）文档标题，显示在左上角与首页，默认 `'Apidoc'`
- `desc`：（选配）文档描述，显示在首页，默认 `''`

### apps

（必须）设置文档的应用/版本列表，数组中的每一项为一个应用：

| 键 | 必填 | 说明 |
| --- | --- | --- |
| `title` | 必须 | 应用标题 |
| `path` | 必须 | 控制器目录地址，也可用数组指定多个目录，如 `['app\demo\controller', 'app\test\controller']` |
| `key` | 必须 | 唯一的 key |
| `password` | 选配 | 该应用的访问授权密码（不配置则使用全局 `auth.password`） |
| `params` | 选配 | 当前应用全局参数（`header` / `query` / `body`，结构同全局 `params`） |
| `responses` | 选配 | 当前应用全局响应体（`success` / `error`，结构同全局 `responses`） |
| `notDebug` | 选配 | 该应用是否不允许调试 |
| `host` | 选配 | 该应用接口调试时使用指定 host 发起请求，通常用于多应用多域名场景 |
| `controllers` | 选配 | 配置后该应用只解析所列出的控制器 |
| `groups` | 选配 | 控制器分组，`title` 分组标题、`name` 分组名；多级分组通过 `children` 嵌套 |
| `items` | 选配 | 多级应用/版本，使用 `items` 嵌套，子项配置参数同上 |

```php
'apps' => [
    [
        'title' => '接口示例',
        'path'  => 'app\demo\controller',
        'key'   => 'demo',
        'password' => '',
        'params' => ['header' => [], 'query' => [], 'body' => []],
        'responses' => ['success' => [], 'error' => []],
        'notDebug' => false,
        'host' => '',
        'controllers' => ['app\admin\controller\BaseDemo'],
        'groups' => [
            ['title' => '基础用法', 'name' => 'base'],
            [
                'title' => '多级分组', 'name' => 'subMenu',
                'children' => [
                    ['title' => '子级1', 'name' => 'sub1'],
                ],
            ],
        ],
        'items' => [
            ['title' => 'V2.0', 'key' => 'v2', 'path' => 'app\test\controller\v2'],
        ],
    ],
],
```

### definitions

（必须）指定通用注释定义文件地址（存放通用字段定义的类），如 `"app\common\controller\Definitions"`。接口注解中可用 `ref` 引用该类中定义的字段。

### auto_url

（必须）自动生成 url 规则，当接口未写 `#[Url("xxx")]` 注解时使用以下规则自动生成：

- `letter_rule`：字母规则，`lcfirst` = 首字母小写，`ucfirst` = 首字母大写
- `prefix`：url 前缀

```php
'auto_url' => [
    'letter_rule' => 'lcfirst',
    'prefix'      => '',
],
```

### auto_register_routes

（选配）是否自动注册路由，默认 `false`。开启后文档解析出的接口会按 `url` + `method` 自动注册路由（依赖各框架 Service 的 `registerRoute` 实现）。

### cache

（必须）缓存配置：`enable` 是否开启缓存，默认 `false`。开启后注解修改不生效，需清除缓存。

### auth

（必须）权限认证配置：

- `enable`：是否启用密码验证
- `password`：全局访问密码
- `secret_key`：密码加密盐
- `expire`：授权访问后的有效期（秒）

```php
'auth' => [
    'enable'     => false,
    'password'   => '123456',
    'secret_key' => 'apidoc#hg_code',
    'expire'     => 24 * 60 * 60,
],
```

### params

全局参数，分为 `header`（请求头）、`query`（URL 查询参数）、`body`（请求体）三类，每项字段结构为：`name` 字段名、`type` 字段类型、`require` 是否必须、`default` 默认值、`desc` 字段描述。

```php
'params' => [
    'header' => [
        ['name' => 'Authorization', 'type' => 'string', 'require' => true, 'desc' => '身份令牌Token'],
    ],
    'query'  => [],
    'body'   => [],
],
```

### responses

全局响应体：

- `success`：成功响应体，字段结构同 header；`main=true` 用来指定接口 `#[Returned]` 参数挂载的节点
- `error`：异常响应体，字段结构同 header，支持 `md` 指向 md 文件

```php
'responses' => [
    'success' => [
        ['name' => 'code', 'desc' => '业务代码', 'type' => 'int', 'require' => 1],
        ['name' => 'message', 'desc' => '业务信息', 'type' => 'string', 'require' => 1],
        ['name' => 'data', 'desc' => '业务数据', 'main' => true, 'type' => 'object', 'require' => 1],
    ],
    'error' => [
        ['name' => 'code', 'desc' => '业务代码', 'type' => 'int', 'require' => 1, 'md' => '/docs/HttpError.md'],
        ['name' => 'message', 'desc' => '业务信息', 'type' => 'string', 'require' => 1],
    ],
],
```

### responses_status

（选配）全局响应状态码，每项含 `name`（状态码）、`desc`（状态码描述）、`contentType`（选配，状态码内容类型）：

```php
'responses_status' => [
    ['name' => '200', 'desc' => '请求成功'],
    ['name' => '401', 'desc' => '登录令牌无效', 'contentType' => ''],
],
```

### 其它配置键

| 配置键 | 说明 |
| --- | --- |
| `route_prefix` | （选配）apidoc 路由前缀，默认 `/apidoc` |
| `default_author` | （选配）默认作者 |
| `default_method` | （选配）默认请求类型，未写 `#[Method]` 时使用，默认 `GET` |
| `allowCrossDomain` | （选配）是否允许跨域访问 |
| `ignored_methods` | （选配）解析时忽略的方法 |
| `database` | （选配）数据库配置（用于数据表字段引用，配合 `table` / `ref` 使用） |
| `docs` | （选配）Markdown 文档配置，每项含 `title`（文档标题）、`path`（.md 文件地址）、`appKey`（指定应用/版本），多级分组用 `children` 嵌套 |
| `generator` | （选配）代码生成器配置，注意是二维数组，每个元素为一个生成任务（含 `title`、`enable`、`form` 表单配置、`files` 文件生成配置、`table` 数据表配置等） |
| `code_template` | （选配）代码模板配置（前端代码生成用），每项含 `title`、`select_mode`（controller/api）、`template`（模板文件）、`language`、`form` 等 |
| `share` | （选配）接口分享功能：`enable` 是否开启；`actions` 自定义分享按钮操作，二维数组，每个配置为一个按钮（`name` 操作名称、`click` 点击时执行的方法，返回 js 脚本，可用 `downloadFile("下载地址","名称")` 下载文件） |

> 说明：官方文档中的 `enable`（总开关）、`ignored_annitation`、`debug_events`、`parsesAnnotation` 等配置项在本项目 `src/config.php` 中未提供，如需使用请自行扩展，本文档不赘述。

## 五、使用（建议及规范）

### 建议

- 本项目仅支持 PHP 8 及以上版本，请一律使用 **PHP 8 原生 attributes** 书写注解
- 使用 PHPStorm 可安装 Annotations 插件，支持注解的语法提示及自动完成
- 建议参考官方演示项目 [apidoc-demos](https://github.com/HGthecode/apidoc-demos) 及基于 Webman 的 [PHP8 原生注解示例](https://github.com/HGthecode/apidoc-demos/tree/webman)

### 书写规范

- 控制器必须 `use` 引入注解命名空间：`use erikwang2013\apidoc\annotation as Apidoc;`（或逐个引入具体注解类）
- PHP8 原生注解写法：`#[注解名("参数值", 子参数名="子参数值", ...)]`，推荐使用命名参数（如 `#[Apidoc\Query(name: "name", type: "string")]`）
- 多个注解可以合并写在一个 `#[...]` 内，用逗号分隔

### 注解一览

所有注解类位于 `erikwang2013\apidoc\annotation` 命名空间：

| 注解 | 作用 | 使用位置 |
| --- | --- | --- |
| `Title` | 控制器/接口名称 | 类、方法 |
| `Desc` | 描述 | 类、方法 |
| `Url` | 接口地址 | 方法 |
| `Method` | 请求类型（GET/POST/PUT/PATCH/DELETE） | 方法 |
| `Group` | 分组（配合 `apps[].groups` 使用） | 类 |
| `Tag` | 标签 | 类、方法 |
| `Author` | 作者 | 类、方法 |
| `Param` | 请求参数（body） | 方法 |
| `Query` | 请求参数（query） | 方法 |
| `Header` | 请求头参数 | 方法 |
| `RouteParam` | 路由参数 | 方法 |
| `Returned` | 返回参数 | 方法 |
| `ResponseStatus` | 响应状态码 | 方法 |
| `ResponseSuccess` / `ResponseError` | 指定/替换成功、异常响应体 | 方法 |
| `ResponseSuccessMd` / `ResponseErrorMd` | 指定响应体 md 文件 | 方法 |
| `ContentType` | 响应内容类型 | 方法 |
| `Md` | 接口详情 Markdown | 方法 |
| `Before` / `After` | 调试前置/后置事件（事件类继承 `EventBase`） | 方法 |
| `Field` / `Property` | 通用字段定义（用于 definitions 文件中） | 类属性 |
| `AddField` | 给指定注解追加字段 | 方法 |
| `Sort` | 排序 | 类、方法 |
| `RouteMiddleware` | 自动注册路由时指定中间件 | 方法 |
| `NotDebug` | 该接口不允许调试 | 方法 |
| `Not*` 系列（`NotDefaultAuthor` / `NotHeaders` / `NotParams` / `NotQuerys` / `NotResponses` / `NotResponseSuccess` / `NotResponseError` / `NotParse` 等） | 禁用对应的全局默认值/全局参数 | 方法 |

### 完整示例

```php
<?php

namespace app\api\controller;

use app\BaseController;
// 必须的
use erikwang2013\apidoc\annotation as Apidoc;

#[Apidoc\Title("用户")]
#[Apidoc\Desc("用户相关接口")]
#[Apidoc\Group("用户中心")]
class User extends BaseController
{
    #[
        Apidoc\Title("用户详情"),
        Apidoc\Tag("详情"),
        Apidoc\Method("GET"),
        Apidoc\Url("/user/info"),
        Apidoc\Query(name: "id", type: "int", require: true, desc: "用户ID"),
        Apidoc\Query(name: "keyword", type: "string", require: false, default: "", desc: "搜索关键字", mock: "@string"),
        Apidoc\Returned(name: "data", type: "object", desc: "用户信息", children: [
            ['name' => 'id', 'type' => 'int', 'desc' => '用户ID'],
            ['name' => 'nickname', 'type' => 'string', 'desc' => '昵称'],
        ]),
        Apidoc\ResponseStatus(name: "200", desc: "请求成功"),
    ]
    public function info()
    {
        // ...
    }
}
```

### Param / Query / Returned 参数说明

`Param`、`Query`、`Returned` 的构造参数基本一致（`Returned` 额外支持 `replaceGlobal` 替换全局响应体参数；`RouteParam` 无 `table` 参数）：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 字段名 |
| `type` | string | 字段类型（int/string/object/array 等） |
| `require` | bool | 是否必须 |
| `default` | string/int/bool | 默认值 |
| `ref` | string/array | 引用注解/模型（definitions 通用定义） |
| `table` | string | 引用数据表 |
| `field` | string/array | 指定 ref 引入的字段 |
| `withoutField` | string/array | 排除 ref 引入的字段 |
| `desc` | string | 字段说明 |
| `md` | string | Md 文本内容 |
| `mock` | string | Mock 规则 |
| `children` | array | 子参数（嵌套结构） |
| `childrenField` / `childrenDesc` | string | tree 类型时指定 children 字段名/说明 |
| `childrenType` | string | array 类型时指定子节点类型 |

## 六、常用功能

### 1. 在线调试

文档页面中每个接口可直接发起请求调试，支持：

- 全局请求参数（`params.header/query/body` 中配置的项自动带入）
- 每个接口单独填写请求参数（`#[Param]` / `#[Query]` / `#[Header]` / `#[RouteParam]`）
- Mock 参数：开启后请求参数使用 `mock` 规则生成的模拟数据
- 事件处理：通过 `#[Before(...)]`、`#[After(...)]` 注解挂载调试事件（事件类继承 `EventBase`）
- 可通过 `#[NotDebug]` 禁止某接口调试，`apps[].notDebug` 禁止某应用调试

### 2. Mock

在 `#[Param]`、`#[Query]`、`#[Returned]` 中通过 `mock` 参数指定生成规则，如 `mock: "@name"`、`mock: "@phone"`、`mock: "@integer(1,100)"`、`mock: "固定文本"`。文档调试时可将参数切换为 Mock 模式。

### 3. 数据表字段引用（ref / table / field / withoutField）

接口参数可直接引用数据表字段或通用定义，无需逐个手写：

```php
#[
    Apidoc\Query(name: "id", type: "int", require: true, desc: "用户ID"),
    // 引用数据表 user，排除 password 字段
    Apidoc\Returned(table: "user", withoutField: "password", desc: "用户信息"),
    // 只引入指定字段
    Apidoc\Returned(ref: "UserDefinitions", field: ["id", "nickname", "avatar"], desc: "用户信息"),
]
public function info() {}
```

- `table` 指定数据表，需在 `database` 配置项中配置数据库连接
- `field` 只引入指定字段，`withoutField` 排除指定字段
- `ref` 引用 `definitions` 中定义的通用字段类（类中用 `#[Field]` / `#[Property]` 声明）

### 4. Json / TypeScript 生成

文档页面对每个接口自动生成对应的 Json 请求/响应示例与 TypeScript 类型定义，可直接复制用于前端开发。

### 5. 接口生成器

文档页面提供接口管理能力，可指定应用/接口生成分享链接、导出 `swagger.json` 文件。

### 6. 代码生成器

配置 `generator`（二维数组，每个元素为一个生成任务：表单 `form`、文件生成 `files`、数据表 `table`）与 `code_template`（前端代码模板），可在文档页面生成业务代码、数据表及前端 Api 文件。

### 7. 多应用 / 多版本

通过 `apps` 配置多个应用/版本（每个应用有独立的 `key`、`path`、`params`、`responses`、`password` 等），多级应用/版本用 `items` 嵌套，文档自动按应用/版本展示和切换。

### 8. 授权访问

`auth.enable = true` 后访问文档需输入密码。支持全局密码（`auth.password`）与按应用独立密码（`apps[].password`）；`auth.secret_key` 为加密盐，`auth.expire` 控制授权有效期。

### 9. Markdown 文档

配置 `docs` 可将 .md 文件挂载到文档页面：

```php
'docs' => [
    ['title' => 'md语法示例', 'path' => 'docs/Use', 'appKey' => 'demo'],
    [
        'title' => 'HTTP响应编码',
        'children' => [
            ['title' => 'code错误码说明', 'path' => 'docs/HttpCode_${app[0].key}'],
        ],
    ],
],
```

`docs` 的 `path` 与 `generator` 的 `path`、`namespace`、`template` 中支持应用/版本变量 `${app[N].key}`（N 为 `apps` 中的层级索引）。

### 10. 接口分享

配置 `share.enable = true` 开启接口分享；`share.actions` 可自定义分享按钮操作（每个按钮含 `name` 名称与 `click` 回调，回调返回 js 脚本，可用 `downloadFile("下载地址","名称")` 触发文件下载）。

### 11. 自动注册路由

配置 `auto_register_routes = true` 后，解析出的接口会按 `#[Url]` + `#[Method]` 自动注册路由（可配合 `#[RouteMiddleware]` 为接口指定中间件）。该功能依赖各框架 Service 实现，Laravel、ThinkPHP、Hyperf、Webman、Yii2、Yii3 均已提供。

## 七、常见问题

**1. 访问 /apidoc 显示空白或 404？**

检查 `apps` 配置中的 `path` 是否正确指向控制器目录（注意不同框架目录结构差异，如 `app\controller` 与 `app\Controller`、Yii 的 `@app/controllers`），并确认 `definitions` 指向的文件存在。开启 `cache.enable` 后修改注解不生效，可先关闭缓存或清除缓存。Yii2 需确认 `urlManager` 开启了 `enablePrettyUrl`。

**2. 注解不生效 / 接口没解析出来？**

本项目仅支持 PHP 8 attributes，请确认书写的是 `#[Apidoc\Title("xxx")]` 而不是旧版 `@Apidoc\Title` 注释；控制器必须 `use erikwang2013\apidoc\annotation as Apidoc;`（或逐个 use 具体注解类）。建议使用命名参数写法，避免参数顺序问题。

**3. 接口 URL 和预期不符？**

未写 `#[Url]` 的接口按 `auto_url` 规则自动生成（`letter_rule` 控制大小写、`prefix` 加前缀）；如需精确控制，请在方法上显式写 `#[Url("/xxx")]`。

**4. 文档与现有路由冲突？**

`route_prefix` 默认 `/apidoc`，如与项目路由冲突可修改为其他前缀；`auto_register_routes` 开启时注解声明的接口会自动注册路由，如不希望自动注册请保持 `false`。

**5. 与官方 hg/apidoc 的关系？**

本项目是 [HGthecode/apidoc-php](https://github.com/HGthecode/apidoc-php) 的 fork（包名 `erik/apidoc`，命名空间 `erikwang2013\apidoc`），由 erik 维护：移除了 doctrine 旧注解依赖，仅支持 PHP 8 attributes；其余注解类、配置键与官方基本一致，本文档以本项目 `src/config.php` 与 `src/annotation/` 实际内容为准。官方文档站：[https://hgthecode.github.io/apidoc-php](https://hgthecode.github.io/apidoc-php)

## 附录：完整配置代码

```php
<?php
return [
    // （选配）文档标题，显示在左上角与首页
    'title'              => 'Apidoc',
    // （选配）文档描述，显示在首页
    'desc'               => '',
    // （必须）设置文档的应用/版本
    'apps'           => [
        [
            // （必须）标题
            'title'=>'Api接口',
            // （必须）控制器目录地址，也可以是数组来指定多个控制器目录
            'path'=>'app\controller',
            // （必须）唯一的key
            'key'=>'api',
            // （选配）该应用的访问授权密码
            'password' => '',
            // （选配）当前应用全局参数
            'params'=>['header'=>[], 'query'=>[], 'body'=>[]],
            // （选配）当前应用全局响应体
            'responses'=>['success'=>[], 'error'=>[]],
            // （选配）该应用是否不允许调试
            'notDebug'=>false,
            // （选配）该应用接口调试时使用指定host发起请求
            'host'=>'',
            // （选配）配置后只解析所列出的控制器
            'controllers'=>[],
            // （选配）控制器分组，多级分组用children嵌套
            'groups'=>[],
            // （选配）多级应用/版本使用items嵌套
            'items'=>[],
        ]
    ],

    // （必须）指定通用注释定义的文件地址
    'definitions'        => "app\common\controller\Definitions",
    // （必须）自动生成url规则，当接口不添加#[Url("xxx")]注解时使用以下规则自动生成
    'auto_url' => [
        // 字母规则，lcfirst=首字母小写；ucfirst=首字母大写
        'letter_rule' => "lcfirst",
        // url前缀
        'prefix'=>"",
    ],
    // （选配）是否自动注册路由
    'auto_register_routes'=>false,
    // （必须）缓存配置
    'cache'              => [
        // 是否开启缓存
        'enable' => false,
    ],
    // （必须）权限认证配置
    'auth'               => [
        // 是否启用密码验证
        'enable'     => false,
        // 全局访问密码
        'password'   => "123456",
        // 密码加密盐
        'secret_key' => "apidoc#hg_code",
        // 授权访问后的有效期
        'expire' => 24*60*60
    ],
    // 全局参数
    'params'=>[
        // （选配）全局的请求Header
        'header'=>[
            // name=字段名，type=字段类型，require=是否必须，default=默认值，desc=字段描述
            ['name'=>'Authorization','type'=>'string','require'=>true,'desc'=>'身份令牌Token'],
        ],
        // （选配）全局的请求Query
        'query'=>[],
        // （选配）全局的请求Body
        'body'=>[],
    ],
    // 全局响应体
    'responses'=>[
        // 成功响应体
        'success'=>[
            ['name'=>'code','desc'=>'业务代码','type'=>'int','require'=>1],
            ['name'=>'message','desc'=>'业务信息','type'=>'string','require'=>1],
            // main=true来指定接口Returned参数挂载节点
            ['name'=>'data','desc'=>'业务数据','main'=>true,'type'=>'object','require'=>1],
        ],
        // 异常响应体
        'error'=>[
            ['name'=>'code','desc'=>'业务代码','type'=>'int','require'=>1,'md'=>'/docs/HttpError.md'],
            ['name'=>'message','desc'=>'业务信息','type'=>'string','require'=>1],
        ]
    ],
    // （选配）全局响应状态码
    'responses_status'=>[
        ['name'=>'200','desc'=>'请求成功'],
        ['name'=>'401','desc'=>'登录令牌无效','contentType'=>''],
    ],
    // （选配）apidoc路由前缀,默认apidoc
    'route_prefix'=>'/apidoc',
    //（选配）默认作者
    'default_author'=>'',
    //（选配）默认请求类型
    'default_method'=>'GET',
    // （选配）允许跨域访问
    'allowCrossDomain'=>false,

    // （选配）解析时忽略的方法
    'ignored_methods'=>[],

    // （选配）数据库配置
    'database'=>[],
    // （选配）Markdown文档
    'docs'              => [],
    // （选配）代码生成器配置 注意：是一个二维数组
    'generator' =>[],
    // （选配）代码模板
    'code_template'=>[],
    // （选配）接口分享功能
    'share'=>[
        // 是否开启接口分享功能
        'enable'=>false,
        // 自定义接口分享操作，二维数组，每个配置为一个按钮操作
        'actions'=>[]
    ],
];
```
